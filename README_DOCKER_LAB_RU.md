# ACC — синтетический ИИ-патч + изолированные Docker-тесты

**Эксперимент. Не подключено к RC83. Не обрабатывает закрытые исходники.**

На стандартном бесплатном исполнителе публичного репозитория только один запуск:
1. Загрузить публичные GGUF-веса Qwen2.5-Coder-1.5B, проверить опубликованный SHA-256 `cc324af070c2ecbfd324a30884d2f951a7ff756aba85cb811a6ec436933bb046`.
2. Получить три искусственных арифметических выражения, проверить их безопасным AST, **не выполнять сгенерированный код на хосте**.
3. Создать временные оригинальные (ошибочные) и исправленные искусственные файлы. Проверить, что исходная ошибка воспроизводится (RED), а исправление проходит unit tests (GREEN).
4. Выполнить RED и GREEN **только в Docker**, сеть отключена, корневая система и исходники только для чтения, без токенов, с удалёнными capabilities, непривилегированным пользователем и ограниченными CPU/RAM/PID.
5. Сохранить JSON только на один день и не повторять автоматически после отказа.

Используется неизменяемый образ Python с точным индексным digest издателя:
`python:3.11.15-slim-bookworm@sha256:d29f48a31a8b408ed19272ca1e7b10ebae13b240a27e862d3d4217c528e2e0c3`.
Он не будет заменён автоматически на другой образ, даже при проблеме загрузки.

**Один разрешённый запуск:** `acc-synthetic-qwen15b-docker-20261123` и файл `.acc-trial-trigger`, содержащий `ACC_SYNTHETIC_QWEN15B_DOCKER_ONCE_20261123`. `ubuntu-latest`, до 20 минут, GitHub `contents: read`, без секретов, без платных API.

Проверки Docker отсутствуют в локальной среде ChatGPT и должны оцениваться только по реальному GitHub run + JSON-артефакту. Успех синтетических тестов не является достаточной приёмкой для RC83, PDF, GUI или Windows EXE.
