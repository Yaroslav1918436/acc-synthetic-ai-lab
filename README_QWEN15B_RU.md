# ACC — отдельное испытание Qwen2.5-Coder-1.5B (только искусственный код)

Эта ветка изолирована от приватного RC83. **Только публичные синтетические задачи**; запрещены документы, токены, закрытые исходники, платные сервисы.

* Исходная модель: Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF, ревизия файла `2ab9f8f`, `qwen2.5-coder-1.5b-instruct-q4_k_m.gguf`.
* Официальный SHA-256: `cc324af070c2ecbfd324a30884d2f951a7ff756aba85cb811a6ec436933bb046`.
* Один запуск через точный маркер `ACC_SYNTHETIC_QWEN15B_TRIAL_ONCE_20261123`; `ubuntu-latest`, 20 минут, `contents: read`, без секретов.
* Модель отвечает на три простых задания по арифметике/логике. Код ИИ НЕ исполняется; AST проверяется только как данные.
* В JSON сохраняются только ограниченные фрагменты синтетических ответов и результаты статической проверки. `success` GitHub Actions означает только успешное выполнение программы, **не компетентность ИИ-разработчика**.
* До проверки реальной модели в изолированном исполнителе на более сложных синтетических задачах запрещено давать ей закрытый код RC83 или автоматически изменять приложения.
