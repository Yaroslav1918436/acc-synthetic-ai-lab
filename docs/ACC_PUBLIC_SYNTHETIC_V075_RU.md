# АСС v0.7.5 — безопасный публичный синтетический workflow

24.11.2026. **Статус: отдельная тестовая ветка и черновой PR.** Программа для искусственного примера прошла локальную проверку; облачный GitHub Actions workflow ещё НЕ выполнялся и НЕ добавлен в основной `main`.

## Зачем

Публичные стандартные runners GitHub Actions по официальной документации бесплатны. В закрытом репозитории возможны расчётные расходы, поэтому правила проекта запрещают запуск его Actions без доказанной гарантии $0. Cloudflare Workers Free подходит для контроля метаданных, но не для выполнения длительной ИИ-разработки. Этот публичный workflow нужен только как доказательство отдельного облачного выполнения **без ПК**, не как способ перенести в публичную систему закрытый код.

## Ограничения по умолчанию

- Репозиторий строго `Yaroslav1918436/acc-synthetic-ai-lab` (проверяется и в job, и в Python).
- Единственный разрешённый `task_id` — `lab-artifact-001`.
- Вход — не файл или пользовательский код, а заранее известный SHA-256 искусственной строки `export function syntheticAnswer() { return 1; }`.
- Исправление только `return 1` → `return 2`. Изменённый искусственный результат проверяется по точному SHA-256.
- Job запускается исключительно по `workflow_dispatch`, без `push`, `schedule` и действий при PR. `ubuntu-latest`, тайм-аут 5 минут, `permissions: contents: read`, без внешних `uses`, Docker, API и модели.
- Успешный ответ содержит JSON-квитанцию и её SHA-256 с `GITHUB_RUN_ID`, commit SHA, меткой `SYNTHETIC_NEEDS_REVIEW`. Писать `COMPLETED/PASS` для закрытого проекта запрещено.
- Временные файлы кандидата удаляются после проверки; итоговая квитанция фиксируется в журнале и Step Summary, без загрузки artifacts или сохранения клиентских данных.
- Программная проверка НЕ доказывает изоляцию произвольного вредоносного кода, отключение сети на GitHub runner или пригодность ИИ для реальной разработки.

## Выполненная проверка

Тестовый Python-код извлечён **непосредственно из YAML workflow** и запущен локально с реальными искусственными переменными GitHub. `python3 -m unittest discover -s tests -q`: **17/17 PASS**, ноль ошибок; `compileall`: PASS. Покрыты положительная квитанция и SHA, отказ от ID другой задачи/репозитория, некорректные SHA и Run ID, неподходящий каталог, попытка shell injection, отсутствие сетевых загрузок, разрешения только для чтения и отсутствие автоматических триггеров.

**Не проверено:** выполнение этого workflow на настоящем GitHub-hosted runner и чтение его лога из облачного АСС. Это отдельные этапы, которые нельзя объявлять PASS по результатам локального Python.

## Следующий шаг без раскрытия приватного кода

После проверки чернового PR отдельным решением включить workflow в публичный `main`, затем подготовить в Cloudflare разрешённый public-only токен GitHub Actions с минимальными правами и однократный D1-журнал диспетчеризации. Никогда не отправлять в публичный workflow закрытые файлы, код RC83, токены, почту или коммерческие документы. Нельзя автоматически объединять PR или запускать приватные GitHub Actions.
